# Sistema de Consulta - Valores a Receber

Este projeto é um portal de consulta oficial para Valores a Receber, integrado com sistemas de segurança e acessibilidade.

## Funcionalidades
- **Segurança Avançada**: Camuflagem de palavras-chave no código fonte.
- **Acessibilidade**: Sistema de Talk (TTS) para usuários com deficiência visual.
- **Validação**: Verificação rigorosa de documentos (CPF/CNPJ).
- **Integração WhatsApp**: Funil de atendimento automático com processamento de dados.
- **Captcha Dinâmico**: Proteção contra bots e automações.

## Como Executar

1. Instale as dependências:
   `npm install`

2. Inicie o servidor de desenvolvimento:
   `npm run dev`
